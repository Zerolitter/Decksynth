# Luna demo kits

Decksynth includes five starter kits for the sixteen-pad Drum Rack:

- **Neon Blueprint** — bright digital drums
- **Chrome 909** — polished club drums
- **Submerged 808** — deep low-end drums
- **Studio Walnut** — close-miked acoustic drums
- **Hand Drum Bloom** — djembe, conga, and bongo percussion

Each kit contains sixteen synthetic WAV samples mapped to the canonical Drum
Rack pads.

The kits are bundled under `ui-next/demo-kits` and are selected automatically
when no user sample-library folder has been configured. Choosing another
library leaves the bundled demos unchanged.

Original source samples, recipes, and demo-loop files are not included.
