# Luna demo kits

Decksynth can use five Luna demo kits from the local sample library:

- **Neon Blueprint** — bright digital drums
- **Chrome 909** — polished club drums
- **Submerged 808** — deep low-end drums
- **Studio Walnut** — close-miked acoustic drums
- **Hand Drum Bloom** — djembe, conga and bongo percussion

## Local setup

The five generated kits are bundled at `ui/demo-kits`. Decksynth selects that folder automatically when no user sample-library root has been saved.

To use your own kits instead, open the Drum Rack kit browser and choose your sample folder.

Search for the five kit names above, audition their WAVs, and load a kit. Choosing another root is saved in the user-local Decksynth data directory and does not modify the bundled demos.

## Distribution boundary

The bundled WAVs are synthetic generated outputs recreated from the owner's sample list. Original source samples, recipes, and demo-loop files are not included.
