# Decksynth demo kits

These five generated Luna kits ship as a small starter library for the Drum Rack:

- Neon Blueprint
- Chrome 909
- Submerged 808
- Studio Walnut
- Hand Drum Bloom

Each kit contains the 16 canonical Drum Rack pad WAVs. Demo loops and recipe/source metadata stay outside the application package.

Decksynth selects this folder automatically only when no user sample-library root has been saved. Choosing another sample folder leaves the bundled demos untouched.
